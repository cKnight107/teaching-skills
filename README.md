# teaching-skills · 教学技能库

让 AI 按教材范围协助备课、讲解和复习。适合教师，也适合希望用 AI 辅助教学的用户。

这里的 **Skill（技能）** 是一套给 AI 阅读的说明和参考资料。安装到支持 Agent Skills 的工具后，你可以用自然语言提出教学需求，AI 会按技能中的章节、方法和教学要求组织回答。无需编写代码。

## 可以用来做什么？

- **备课**：生成学习目标、课堂问题链、教学流程、板书和课后练习。
- **讲解**：解释概念、计算步骤和证明思路，说明为什么这样做。
- **分析错题**：找出学生首先出错的步骤，提供追问和针对性练习。
- **安排复习**：整理知识关系、常见题型和易错条件。

使用时说明教材版本、教学主题、学生基础和课时，回答会更贴合课堂。生成结果仍需教师核对后使用。

## 新手如何开始？

### 方法一：让你的 Agent 帮你安装

如果你使用的 AI 工具能够读取仓库、操作本地文件并支持 Agent Skills，可以直接复制下面这段话给它：

> 请从 https://github.com/cKnight107/teaching-skills 安装 bnu-math-grade9-volume1 技能，安装到我当前使用的 Agent 的技能目录。请保留整个技能文件夹及其相对目录结构，不覆盖已有同名技能；安装完成后告诉我如何调用它。

安装完成后，按工具提示重新加载技能或开启新会话，再试试下一节的提问。

### 方法二：在终端安装

适合已经安装 Node.js 和 Git 的用户。打开终端，粘贴下面的命令：

```bash
npx skills add cKnight107/teaching-skills --skill bnu-math-grade9-volume1 --global
```

根据提示选择你正在使用的 Agent。`--global` 表示安装到个人技能目录，便于在不同项目中使用。安装工具及参数说明见 [Skills CLI 官方文档](https://github.com/vercel-labs/skills)。

如果提示找不到 `npx` 或 `git`，可以改用方法一，让 Agent 协助配置环境。

### 方法三：手动下载

1. 在仓库页面点击绿色 **Code** 按钮，再点击 **Download ZIP**。
2. 解压后，找到 `skills/bnu-math-grade9-volume1` 文件夹。
3. 将**整个文件夹**放入你的工具指定的技能目录，保留其中的 `chapters/` 等资料。具体目录以该工具说明为准。
4. 重新加载技能或开启新会话，用技能名称提出需求。

只复制 `SKILL.md` 会丢失章节资料。普通聊天工具若不支持安装技能，可以上传整个技能目录中的 Markdown 文件作为参考；是否支持多文件和如何上传，以工具实际功能为准。

## 复制这些提问试试看

**准备一节课：**

> 使用 bnu-math-grade9-volume1，为“菱形的性质与判定”设计一节40分钟的课。学生已学过平行四边形，证明能力较弱。请给出学习目标、课堂问题链、教学流程、板书和3道练习及答案。

**把知识讲清楚：**

> 使用 bnu-math-grade9-volume1，向九年级学生讲解一元二次方程的配方法。请从一个简单例子开始，逐步说明每一步的理由，并给一道自编练习。

**分析学生错误：**

> 使用 bnu-math-grade9-volume1，分析学生“对角线相等的四边形一定是矩形”这句话错在哪里。请给出反例、课堂追问和一道纠错练习。

**组织复习：**

> 使用 bnu-math-grade9-volume1，设计二次函数章节的45分钟复习课，重点串联图象、顶点、最值和一元二次方程，附分层练习及答案。

涉及具体教材题目时，请同时提供完整题干和清晰题图。

## 给 Agent 的读取说明

1. 从上方技能列表选择匹配教材与任务的技能，先读取对应目录的 `SKILL.md`。
2. 根据其中的主题索引读取相关 `chapters/*.md`，再生成详细教案或讲解。跨章任务读取涉及的章节。
3. 复习概览可先读 `cheatsheet.md`；题型方法读 `patterns.md`；术语读 `glossary.md`。按需求读取，不必一次加载所有资料。
4. 遵守技能中的数学条件和来源标注要求。自编题、变式与课堂安排应标明为教学建议，不虚构教材题号、页码或原话。
5. 缺少题图、几何标注或关键题目条件时，向用户索取完整材料；不要推测缺失图形。安装时保留相对路径，不覆盖同名目录。

## 仓库里有哪些文件？

```text
skills/
└── bnu-math-grade9-volume1/
    ├── SKILL.md        # 技能入口、教学规则与章节索引
    ├── chapters/      # 各章教学参考
    ├── glossary.md    # 术语
    ├── patterns.md    # 题型与方法
    └── cheatsheet.md  # 复习速查
```

每个技能独立放在 `skills/` 下，可以单独安装和更新。后续教材技能也会按这一结构集中维护。

## 是否需要原教材 PDF？

日常备课、概念讲解和复习主要使用上述 Markdown 资料，**不需要先下载原 PDF**。仓库不包含教材 PDF、完整原文提取结果或整页截图。

技能是教材内容的结构化提炼与教学建议，不是全书答案库。要处理依赖原图、标注或完整原题的任务，需要你提供相应题目或合法取得的教材页面。部分图形未逐页核对，具体限制见技能的“来源与边界”。

教材著作权归相应权利人所有。仓库公开不等于取得原教材的再分发授权；请按资料来源和授权范围使用、分享相关内容。

## 技能是如何制作的？

本仓库的教材技能借助 [book-to-skill](https://github.com/virgiliojr94/book-to-skill) 提取资料，并由 Agent 整理成教学说明与章节参考。

**teaching-skills** 存放制作好的教学技能，供用户安装使用；**book-to-skill** 是把书籍和文档转换成技能的制作工具。使用本仓库的技能无需安装 book-to-skill。如果你想将自己的书籍或文档制作成技能，可以查看该项目的说明。
