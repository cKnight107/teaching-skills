# 教师备课速查

## 方法决策

| 当你看到 | 优先做什么 | 必查条件 |
|---|---|---|
| 平行四边形对角线垂直 | 判菱形 | 已知或已证平行四边形 |
| 平行四边形对角线相等 | 判矩形 | 已知或已证平行四边形 |
| 要证正方形 | 选“矩形+等邻边”或“菱形+直角”等路线 | 每个前提有依据 |
| 方程有易分解因式 | 先移项，再因式分解 | 右边为0；不除未知因式 |
| 求方程根的情况 | 计算$\Delta$ | 一般式、$a\ne0$ |
| 仅求两根和积 | 用$-b/a,c/a$ | 实根存在，含重根 |
| 相似图形求边长 | 先定对应，再列比例 | 相似判定先成立 |
| 相似图形求面积 | 用边比的平方 | 比的顺序一致 |
| 原点位似坐标 | 两坐标同乘$k$ | 相似比是$|k|$ |
| 太阳影长测高 | 建相似比例 | 同时、竖直、同一水平地面 |
| 灯光影子 | 画点光源模型 | 不套太阳影长比例 |
| 三视图 | 按长高/宽高/长宽校验 | 统一正面、正投影 |
| 函数求顶点 | 配方或用轴公式 | $a\ne0$、负号正确 |
| 实际最值 | 先定义域，再查顶点 | 端点是否可取、是否要求整数 |
| 数概率 | 编号、列举、查等可能 | 顺序与放回机制 |
| 用频率估计概率 | 多次重复同机制试验 | 分母是完整试验次数 |

## 公式与条件

- 菱形：$S=d_1d_2/2$；边长$s$满足$s^2=(d_1/2)^2+(d_2/2)^2$。
- 正方形：$d=s\sqrt2$；$S=d^2/2$。
- 一元二次方程：$\Delta=b^2-4ac$；$\Delta\ge0$时$x=(-b\pm\sqrt\Delta)/(2a)$。
- 相似比$k>0$：对应长度、周长比$k$，面积比$k^2$。
- 二次函数：$h=-b/(2a)$，$k=(4ac-b^2)/(4a)$；顶点$(h,k)$、轴$x=h$。
- 有限等可能结果：$P(A)=m/n$；大量重复实验以频率$m/n$估计概率，估计有波动。

## 课堂快速诊断

| 学生表现 | 一个追问或动作 |
|---|---|
| 用图形外观作证明 | 哪个已知条件保证这个性质？ |
| 判定漏前提 | 如果不要求平行四边形，能画反例吗？ |
| 开平方只有一个解 | 负数的平方也能等于该数吗？ |
| 比例顺序不一致 | 先用同色标两图对应点 |
| 面积比等于长度比 | 边长扩大2倍的方格面积变几倍？ |
| 顶点左右符号错 | 令平方中的括号为0 |
| 极值超出实际范围 | 将范围和顶点画在同一数轴上 |
| 概率按颜色类别均分 | 每类背后有几个等可能对象？ |
| 频率当确定概率 | 另一组实验为何可能不同？ |
