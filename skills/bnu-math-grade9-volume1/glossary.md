# 术语表

按中文术语拼音大致排列；括号给出章节，便于回读。

- **对称轴**：使抛物线两侧对应点互相对称的直线；二次函数顶点式的轴为$x=h$。（ch05）
- **顶点**：抛物线与对称轴相交的点；$y=a(x-h)^2+k$的顶点为$(h,k)$。（ch05）
- **等可能基本结果**：一次完整试验中可能性相同、互不重复的具体结果；计数概率公式的前提。（ch06）
- **放回试验**：抽取后将对象放回并重新混合，再进行后续抽取。（ch06）
- **根**：使方程成立的未知数值；本册一元二次方程在实数范围讨论。（ch02）
- **根与系数关系**：$ax^2+bx+c=0$有实根时，根和$-b/a$、根积$c/a$。（ch02）
- **公式法**：整理一般式、计算判别式并用求根公式求实根。（ch02）
- **概率**：在给定随机机制下事件发生可能性的数值，范围为$[0,1]$。（ch06）
- **黄金分割**：较长段与全长之比等于较短段与较长段之比，值为$(\sqrt5-1)/2$。（ch03）
- **矩形**：有一个角为直角的平行四边形。（ch01）
- **菱形**：有一组邻边相等的平行四边形。（ch01）
- **配方法**：通过等价变形构造完全平方，解方程或确定二次函数顶点。（ch02、ch05）
- **判别式**：$\Delta=b^2-4ac$，符号决定一元二次方程实根个数。（ch02、ch05）
- **平行投影**：平行光线形成的投影。（ch04）
- **频率**：事件发生次数除以试验次数；大量重复时可用来估计概率。（ch06）
- **俯视图**：从上面作正投影得到的视图，表现长与宽。（ch04）
- **相似多边形**：对应角分别相等、对应边成比例的多边形。（ch03）
- **相似比**：按指定顺序两个相似图形对应长度的比，取正值。（ch03）
- **树状图**：按试验阶段分支，列举完整路径和基本结果的图。（ch06）
- **位似**：对应点连线通过同一中心且对应点到中心距离比固定的相似。（ch03）
- **一元二次方程**：一般形式$ax^2+bx+c=0$，系数常数、$a\ne0$的整式方程。（ch02）
- **因式分解法**：将方程化为乘积为0，令各因式分别为0求解。（ch02）
- **正方形**：邻边相等且一个角为直角的平行四边形，同时为菱形与矩形。（ch01）
- **正投影**：光线垂直投影面的平行投影。（ch04）
- **中心投影**：由同一点发出的光线形成的投影。（ch04）
- **主视图**：从正面作正投影得到的视图，表现长与高。（ch04）
- **左视图**：从左面作正投影得到的视图，表现宽与高。（ch04）
- **二次函数**：$y=ax^2+bx+c$，系数常数且$a\ne0$的函数。（ch05）
- **抛物线**：本册二次函数图象的形状；性质由系数和顶点决定。（ch05）
